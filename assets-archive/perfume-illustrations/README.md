# Flakon illyustratsiyalari (zaxira rasmlar)

Demo katalog uchun chizilgan oddiy SVG illyustratsiyalar — hech qanday litsenziya cheklovi yo‘q.
Rasmi yo‘q atirlar uchun vaqtinchalik rasm sifatida ishlatish mumkin.

| Fayl | Ko‘rinish |
|---|---|
| `rose.svg` | pushti flakon — ayollar, gulli/shirin |
| `blue.svg` | moviy flakon — erkaklar, yangi/sitrusli |
| `amber.svg` | amber flakon — sharqona, shirin |
| `black.svg` | qora flakon — erkaklar, kechki/yog‘ochli |
| `gold.svg` | oltin flakon — hashamatli, sharqona |
| `oil.svg` | moyli atir (roll-on) |

Saytda ishlatish uchun: `frontend/public/images/perfumes/` ga ko‘chiring va mahsulot rasmiga
`/images/perfumes/<fayl>.svg` deb yozing.
